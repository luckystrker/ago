## Что сделать
Четыре расхождения из аудита `docs/audits/2026-11-19-v1.3.2-deferred.md` (§0 таблица, §1a–1d — там
Python-поведение, наши строки и воспроизведения; пробник аудитора — в его отчёте приёмки). Все живут в `acp/`,
поэтому один тикет и один исполнитель. Порядок — по видимости для пользователя; каждый пункт red-first.

**1. ACP-2 — склейка сообщений (§1b).** Ветка `agent_message_chunk` (`acp/bridge.go` ~440/458/598,
`acp/provider_session.go` `onUpdate`) дописывает текст без сверки `message_id`, и ответ становится конкатенацией
всех сообщений. Python (`bridge.py` `_add_message_text`, `client.py` `texts[-1]`) закрывает сообщение при смене id и
отвечает **последним**. Делать дешёвым вариантом аудита: `currentMessageID` + список сообщений в `providerSession`,
при смене id — `events.ModelMessage` предыдущего, ответ — последнее; сигнатуры публичного API `Bridge` не менять (поля можно только добавлять).
**Семантика `TurnResult.Text` зафиксирована (паритет с Python):** `BridgeState.turn_messages` — список, в разговор
уходит только последнее (`client.py`: `reply = ModelMessage(texts[-1])`). Значит `Text` = текст **последнего**
сообщения хода, не склейка. Нужен доступ ко всем — добавь аддитивно `Messages []string` (API не ломается). Смена смысла
`Text` — поведенческое изменение: строка в `docs/MIGRATION.md` §11 и в D-131, даже если поле то же.
Регрессия: два сообщения с разными id → два сообщения, ответ `"Done: it works."`, `"Let me check."` не попадает во
второе; плюс три Python-теста из `3b5bd7d122` и «пустой чанк не открывает новое сообщение».

**2. ACP-1 — абсолютные пути в `session/new` (§1a).** `AdditionalDirectories` уходят как заданы
(`acp/provider_start.go` ~97). Резолвить рядом с `Config.cwd()` (`acp/provider.go` ~363) через `filepath.Abs`, как
Python `Path(d).resolve()`. И `cwd`, и каталоги — проверять, а не только передавать: тест на провод
(относительный вход → абсолютные значения в JSON `session/new`), отказ `Abs` — ошибка с `%w`.

**3. ACP-3 — uri-only image, `resource`, `resource_link` (§1c.1, §1c.4).**
- *Клиент:* `contentBlock` (`acp/acp.go`) получает `URI`, `Resource{URI, Text, Blob, MimeType}`, `Name`/`Title`;
  `Update.UnmarshalJSON` их читает; аналог Python `block_text`: `"[image] <uri>"`, текст ресурса, `"[resource] <label> (<uri>)"`;
  в `onUpdate` текст — в ответ, blob — в `Files`.
- *Serve:* **только `resource_link`** (вариант (а) аудита): в разборе промпта читать его как `"[resource] <name> (<uri>)"`.
  Объявленные capabilities (`acp/serve.go` ~542-545, `serve_test.go:242`) **не менять** — расширение до Python
  (`image`/`embeddedContext = true`) это отдельное решение, в этот тикет не смешивать.

**4. ACP-4 — `env_var` auth (§1d.3).** Сначала сверка, потом правка. Основание:
`git -C <ag2> show 3b5bd7d122 -- ag2/acp/auth.py ag2/acp/config.py` и `git -C <ag2> show v1.3.2:ag2/acp/auth.py`.

  `docs/MIGRATION.md` §11 и запись **D-131**.
