> **human: required** — тикет меняет границу безопасности: какие файлы shell-инструмент может прочитать при
> `WithShellIgnore`, и превращает «пропуск при ошибке» в отказ. В `done` переводит только владелец.

## Что сделать
Четыре раунда одной правки upstream (`git -C <ag2> show 92e84270`, `c362c5ff`, `3c39c522`, `0c9710c7`; тест-идея —
`b14405f5`) + оговорка из docs-коммита `db7194e8`. Всё живёт в `toolpacks/shellfilter.go` и `toolpacks/shell.go` —
один тикет, раунды строятся друг на друге.

**Утечка (снята при разборе синка).** `NewShellTool(WithShellWorkdir(dir), WithShellReadonly(), WithShellIgnore(".env"))`,
в `dir` лежат `.env` (`SECRET=1`) и `sub/.env` (`SECRET=2`):
`grep -r SECRET .` → `./sub/.env:SECRET=2`, `./.env:SECRET=1`; `diff -r . sub` → сравнивает `.env` и печатает секреты.
`checkIgnore` (~стр. 180) и `checkIgnorePosix` (~стр. 342) смотрят только литеральные слова команды.

Шаги, каждый red-first (первый тест — ровно сценарий выше):
1. **Читатели каталогов.** Для `grep|egrep|fgrep|diff` каждый файл под каталогом-операндом сверяется с `ignore`
   (у `diff` — даже без `-r`); `grep` без файлового операнда — весь workdir. Симлинки — с переходом. Разбор опций grep
   (`-e/-f`, длинные опции по префиксу) ошибается в сторону «меньше операндов» → проверяется весь каталог.
2. **Удалённый бэкенд** (песочница, где дерево с хоста не обойти): `grep|egrep|fgrep|diff` при непустом `ignore` — отказ целиком.
3. **Алиас и реальный путь.** Каталог обходится под именем, которым его назвали (у симлинка-алиаса своё правило), и по
   реальному пути; glob-токен раскрывается в неразрешённые пути; симлинк-петля в предка повторно не раскрывается.
4. **Fail-closed.** Всё, что фильтр не может проверить, — отказ: неразрешимый путь (сейчас `filepath.Abs` на ошибке даёт
   `""` = пропуск, ~стр. 188), нелистуемый каталог, токен с `**`, исчерпанный бюджет. `ignoreCandidates` (~стр. 233) на
   ошибке `filepath.Glob` (~стр. 244) сейчас молча не даёт совпадений — тоже отказ. Абсолютные wildcard внутри workdir проверяются.
5. **Единый бюджет 20 000 записей.** Совпадения wildcard и обойдённые записи тратят **один** счётчик; превышение — отказ
   с подсказкой «назовите каталог поменьше». `filepath.Glob` заменить ручным обходом сегментов через `os.ReadDir`, где
   **каждая прочитанная** запись (и несовпавшая) тратится из бюджета: `src/*/*/nothing` не сканирует дерево бесплатно.
   Каждый wildcard раскрывается один раз. Константа — экспортируемая или опция — реши и запиши в D-133.
6. **Документы.** Описание `WithShellIgnore` (`toolpacks/shell.go:237`) и описание инструмента: `ignore` проверяет
   литеральные пути и обход читателей каталогов, но **не** защищает от программ, исполняющих код (`python -c "open('.env')"`,
   `sh -c`, `env`, `xargs`); то же про blocked-патерны. `docs/DECISIONS.md` **D-133** (контракт фильтра, бюджет, fail-closed,
   отличия Go: обход синхронный в горутине — `asyncio.to_thread` не нужен → `// AGO-DEVIATION`, если отличие видно).
   `docs/MIGRATION.md` — «AG2 v1.3.4 sync». `docs/PORT_STATUS.md` — строка `toolpacks/`.

## Поведенческое изменение / совместимость
- Команды, которые раньше проходили, теперь отклоняются: `grep`/`diff` по каталогу, где есть игнорируемый файл;
  `grep`/`diff` с `ignore` на удалённом бэкенде; пути с `**`; огромные каталоги; неразрешимые пути. Это намеренно
  (граница безопасности) — строка **breaking (по поведению)** в MIGRATION с примерами.
- Сигнатуры опций не меняются; новая константа/опция бюджета — аддитивна.
- Записи: D-133 (обязательно), MIGRATION «AG2 v1.3.4 sync» (обязательно).
