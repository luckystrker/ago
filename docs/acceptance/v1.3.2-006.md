## Review round 1 (verifier DeepSeek)

1. **The test no longer deletes the test process's cwd.** `TestProviderRefusesPathsThatCannotBeResolved` re-execs the
   test binary (`os.Executable()`, `-test.run=^…$`, flag `AGO_ACP_TEST_GONE_CWD=<scenario>`); only the child removes its
   own working directory and asks an agent to start with `CWD="rel"` / `AdditionalDirectories=["extra"]`. The error now
   comes from `workspace()` before any launch (no `chdir rel: no such file or directory` from the launcher), and the
   test asserts the agent never saw `session/new`.
2. **Mutation `%w` → `%v` on the `filepath.Abs` error (`acp/provider.go`, both `Errorf`s) is killed.** The test checks
   `errors.Is(err, ErrWorkspacePath)`, `errors.Is(err, fs.ErrNotExist)` (`filepath.Abs` fails in `os.Getwd`, which
   returns `*os.SyscallError{getwd, ENOENT}` on Linux; `fs.ErrNotExist` is the portable form of that cause) and that
   the message names the path. Output with the mutation applied (the file was restored from a copy afterwards):
