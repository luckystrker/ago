# Ticket 003 — DecisionSet: несколько вопросов одним запросом (AG2 v1.3.2 sync), отчёт исполнителя

Status: **review** (исполнитель `exec-sonnet-003`, база `main` @ `5c79a01`). Upstream: `1c3e0c52f8` (ADR 0038, #3656). Решение: **D-128**.

## Что сделано

1. **Ядро** — `response/decisionset.go` (новый): `NewDecisionSet(Proto) (*DecisionSet, error)`, `IsScalar/Len/Names/Questions/Spec/Render`,
   `ErrInvalidDecisionSet` (оборачивает `ErrNotADecision`), `ErrMissingAnswer`, `AnswerKey`. Скаляр читается ровно как раньше
   (`FromResponse`, из которого вынесена `classifyDecision`); плоский struct → вопрос на поле в порядке полей, ключ — `json`,
   текст — тег `question:"..."`, запасной — `agschema:"description=..."`. `Schema[T]` получил неэкспортируемый `goType()` (порядок и теги читаются рефлексией).
2. **OpenAI Decisions** — `config/openai/decisions.go`: struct → все вопросы одним запросом; `decisionReply` (отказ любого поля →
   `*DecisionRefusedError{Name}`, `metadata = {поле: ответ}`); >400 полей и `Descriptions` со struct — ошибка до запроса;
   `decisionQuestion` принимает имя вопроса. `config/typesafe` не тронут.
3. **Документы** — D-128 (`docs/DECISIONS.md`), `docs/PORT_STATUS.md` (строки `response/`, openai decisions), `docs/MIGRATION.md` §11, пример в `docs/GUIDE.md`.

Тесты: `response/decisionset_test.go`, `config/openai/decisions_set_test.go`, `config/openai/decisions_limit_fixture_test.go` (сгенерированные структуры на 400/401 поле).
