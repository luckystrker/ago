## Спорные места тикета (решено по первоисточнику)

1. **Gemini `total`**: в тексте тикета «`TotalTokens` меньше «вход + выход» не принимается», но точное правило,
   на которое он ссылается (`v1.3.2:ag2/config/gemini/mappers.py`), отдаёт `total_token_count` API как есть;
   `max(...)` делает только Live-вариант (`367119e83a`, не портирован) и ACP/Bedrock. Реализовано по Python:
   total от API, thinking свёрнут в completion (инвариант `total >= prompt+completion` выполняется, потому что
   API считает thoughts внутри total). Тест `total от API меньше суммы` фиксирует pass-through.
2. **«нигде 1950»**: фактический двойной счёт при оставленной поправке AG-UI — 2000 (1050+900+50).
