# Port status

Per-package porting status of the AG2 (Python) → AGo (Go) port, against the binding Go
contracts in `docs/ARCHITECTURE.md`. Deviations from Python parity are marked
`// AGO-DEVIATION` in code and recorded as D-xxx entries in `docs/DECISIONS.md`.
For a class/function-level Python→Go API map, see [docs/MIGRATION.md](MIGRATION.md).

Statuses:

- **ported** — the contracted scope is implemented and green.
- **partial** — implemented and green for the named scope; the listed pieces are deferred.
- **stub** — config/type surface only; the real implementation reports "not implemented".
- **deferred** — deliberately not ported (decision references given).

**Gates, verified 2026-10-31 on the whole module** (fresh run, `-count=1`, from the repo
root — `go.mod` sits there and `examples/` is part of the same module):

- `go build ./...` — success.
- `go vet ./...` — clean.
- `go test -count=1 ./...` — 47 packages `ok`, 0 failures, 0 skipped tests (packages and
  example programs without test files of their own excluded; re-verified 2026-10-31 after
  the D-075/D-076 knowledge+a2ui wave — `gofmt -l` is not meaningful on a CRLF
  working-tree checkout, where autocrlf flags every file).
- contrib modules run their own gates from their directories — `go build ./...`,
  `go vet ./...`, `go test -count=1 ./...`, all green in each of `contrib/knowledgesqlite`,
  `contrib/knowledgeredis`, `contrib/streamredis`, `contrib/wslink`, `contrib/otelx`
  (D-057/D-059/D-064/D-069); CI runs the same loop as a dedicated `contrib` job.
- `go build ./examples/...` and `go vet ./examples/...` — clean; `go run ./examples/<name>`
  of `ask,tools,hitl,subagent,group,knowledge_memory,mcp_http,mcp_stdio,multi_turn,

  offline (scripted configs, no API keys).

## Deferred subsystems (summary)

Everything below is a deliberate decision with a decision record — none of it is silently
missing. After the final wave (D-068..D-073) the only deferred pieces left are the honest
remainders of otherwise-ported slices; there are no whole deferred subsystems beyond the
infrastructure rows in the table above.

- **Redis streams** (`ag2/streams/redis`) and **SQLite/Redis knowledge backends** — ported
  as optional modules outside the core (D-048/D-059): `contrib/streamredis`,
  `contrib/knowledgesqlite`, `contrib/knowledgeredis`; the core itself stays
  dependency-free (D-003), memory backends remain the default.
- **WebSocket network link over the core module** — ported as the optional
  `github.com/luckystrker/ago/contrib/wslink` module (own go.mod, one external dep; D-057).
  **Federation** (`remote.py`) stays an interface stub (`network.RemoteAgentProxy`, no
  implementations; D-056) — single-host subset only; D-010/D-031.
- **Live/voice** (`ag2/live/`, `events/voice.py`) — the realtime audio stack (websocket
  providers, turn detection, barge-in, streaming TTS, sound devices) is the honest
  remainder; the HTTP cascade slice is ported: `github.com/luckystrker/ago/live`
  (D-057, final-wave ledger D-072).
- **Protocol/eval servers** — `acp/`, `a2ui/`; D-010. The a2ui protocol
  subset (v1.0 only) is ported as `github.com/luckystrker/ago/a2ui` (D-076 — see its table
  row). The A2A surface is ported
  transport-level plus wave 2 (D-049/D-050/D-067): push notifications, the
  `urn:ag2:client-tools:v1` extension with client-side execution, context-variable sync
  and HITL over the wire, the REST twin, declarative security schemes. Its honest
  remainders: full history shipping (`ag2.history+json`), reconnect/resubscribe, card
  JWS signing, `validate_input_modes`, cluster mode, tenants — and **gRPC, closed
  permanently** (D-071: JSON-RPC+REST carry the full semantics; protobuf codegen is
  structurally out). The eval harness is ported as `github.com/luckystrker/ago/eval`
  (D-051 + D-061 — attribution, registry, JSONL, diff, stats, concurrency; OTEL trace
  sources stay unported by design). ACP is ported as `github.com/luckystrker/ago/acp`
  (D-052 + D-066 — both stdio roles, cancel/load, the full update vocabulary, mediated
  fs/terminal, the MCP gateway, token auth; the session store, the gateway host
  direction, guard.py and the OAuth/terminal auth kinds deferred — see its table row).
  AG-UI is ported as `github.com/luckystrker/ago/agui` (D-053 + D-065 — held-turn
  interrupts, retention, resume proofs and state snapshots are served; subagent
  suspension and client-state seeding deferred — see its table row).
- **OpenAI Containers** (`ag2/config/openai/containers.py`) — nothing in the ported
  Responses client references them; D-060. The Responses and Decisions APIs themselves are
  ported as `github.com/luckystrker/ago/config/openai` (D-060; closes D-008 — D-068);
  `FileIdInput` maps to `input_file.file_id` there (the Chat-Completions engine still
  rejects it, D-017/D-020).
- **OpenAI Responses specifics** (D-060) — prompt-cache diagnostics events, reasoning-item
  replay, shell command/output delta chunks, skills-into-shell merge, question-instruction
  parts (Decisions), `websocket_base_url`.
- **Ollama streaming** (D-022), **cron/cadence watches** (D-024), the **middleware metrics
  builtin** (D-013). The telemetry builtin is ported as `contrib/otelx` (D-064); its
  content capture, record_usage subscription spans, human-input span and envelope
  traceparent relaying remain deferred with that entry.
- **Toolpacks sandboxes** (D-062) — Docker/Daytona code-execution sandboxes and the
  TypeScript runner stay deferred; the local code runner, shell, filesystem, search and
  skills packs are ported (`github.com/luckystrker/ago/toolpacks`).
